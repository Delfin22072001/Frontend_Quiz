# Quiz Website

A fully responsive, multi-page quiz website built with HTML5, CSS3, JavaScript, and Bootstrap. Take the quiz, see your score, and play again without reloading the page.

**Live Demo:** [https://frontend-quiz-seven-ochre.vercel.app/](https://frontend-quiz-seven-ochre.vercel.app/)

## Features

- Multi-page layout with simple, easy-to-follow navigation
- Fully responsive design with a consistent experience on mobile, tablet, and desktop
- Dynamic score calculation and display using JavaScript and DOM manipulation
- "Play Again" option to restart and retake the quiz without reloading the page
- Deployed on Vercel

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap
- Vercel (deployment)

## Getting Started

No build step is needed.

```bash
git clone https://github.com/Delfin22072001/<repo-name>.git
cd <repo-name>
```

Open `index.html` in your browser. You can also use the Live Server extension in VS Code to reload the page automatically as you edit.

## What I Learned

- Building responsive layouts with Bootstrap
- Updating the page dynamically with JavaScript and DOM manipulation
- Calculating and displaying results without page reloads
- Deploying a static site on Vercel
